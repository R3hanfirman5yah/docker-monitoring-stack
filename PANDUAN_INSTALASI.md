# 📋 PANDUAN INSTALASI LENGKAP - Docker Monitoring Stack\n\n## 🎯 Tujuan\nSetup monitoring logs server dan jaringan di perusahaan dengan Docker, Portainer, Grafana, Loki, dan Prometheus.\n\n---\n\n## 🚀 STEP 1: Persiapan Ubuntu Server\n\n### 1.1 Akses Ubuntu Server via SSH\n\n**Dari laptop/komputer Anda:**\n```bash\nssh username@IP_UBUNTU_SERVER\n# Contoh:\nssh admin@192.168.1.100\n```\n\n### 1.2 Update sistem\n\n```bash\nsudo apt-get update\nsudo apt-get upgrade -y\nsudo apt-get install -y curl git\n```\n\n---\n\n## 🐳 STEP 2: Install Docker Engine\n\n### Cara 1: Menggunakan Script Otomatis (RECOMMENDED)\n\n```bash\n# Download repository\ngit clone https://github.com/R3hanfirman5yah/docker-monitoring-stack.git\ncd docker-monitoring-stack\n\n# Jalankan script instalasi\nchmod +x scripts/install-docker.sh\nsudo ./scripts/install-docker.sh\n```\n\n**Setelah instalasi selesai, jalankan:**\n```bash\nnewgrp docker\n```\n\n**Verifikasi instalasi:**\n```bash\ndocker --version\ndocker run hello-world\n```\n\n---\n\n### Cara 2: Manual Step-by-Step\n\nJika script tidak bekerja, ikuti langkah manual:\n\n```bash\n# 1. Install dependencies\nsudo apt-get install -y apt-transport-https ca-certificates curl gnupg lsb-release\n\n# 2. Tambah Docker GPG key\ncurl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg\n\n# 3. Setup Docker repository\necho \"deb [arch=amd64 signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable\" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null\n\n# 4. Install Docker dan Docker Compose\nsudo apt-get update\nsudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin\n\n# 5. Tambah user ke docker group\nsudo usermod -aG docker $USER\n\n# 6. Verify\ndocker --version\n```\n\n---\n\n## 📁 STEP 3: Setup Repository Files\n\n### 3.1 Clone atau masuk ke folder project\n\n```bash\ncd docker-monitoring-stack\n```\n\n### 3.2 Cek struktur folder\n\n```bash\nls -la\n```\n\nShould see:\n```\n.\n├── docker-compose.yml\n├── .env\n├── README.md\n├── PANDUAN_INSTALASI.md\n├── scripts/\n│   ├── install-docker.sh\n│   ├── start-stack.sh\n│   └── stop-stack.sh\n└── config/\n    ├── prometheus/\n    │   ├── prometheus.yml\n    │   └── alert.rules\n    ├── loki/\n    │   └── local-config.yaml\n    ├── promtail/\n    │   └── config.yaml\n    └── grafana/\n        ├── grafana.ini\n        └── provisioning/\n            ├── datasources/\n            └── dashboards/\n```\n\n### 3.3 Setup permissions\n\n```bash\nchmod +x scripts/*.sh\n```\n\n---\n\n## ⚙️ STEP 4: Konfigurasi File (Optional)\n\n### 4.1 Ubah Environment Variables (`.env`)\n\n**Edit file:**\n```bash\nnano .env\n```\n\n**Atau gunakan cat untuk lihat:**\n```bash\ncat .env\n```\n\n**Konfigurasi yang penting:**\n```env\n# Timezone\nTZ=Asia/Jakarta\n\n# Grafana Admin\nGF_SECURITY_ADMIN_USER=admin\nGF_SECURITY_ADMIN_PASSWORD=admin123      # ⚠️ UBAH PASSWORD INI!\n\n# Hostname\nHOSTNAME=ubuntu-server\n```\n\n**Ubah password (RECOMMENDED):**\n```bash\n# Edit .env\nsudo nano .env\n\n# Ubah baris:\nGF_SECURITY_ADMIN_PASSWORD=password_anda_yang_kuat\n\n# Simpan: Ctrl+O, Enter, Ctrl+X\n```\n\n### 4.2 Verifikasi docker-compose.yml\n\n```bash\n# Check syntax\ndocker compose config\n```\n\nJika tidak ada error, berarti config OK ✅\n\n---\n\n## 🎬 STEP 5: Jalankan Stack (CARA PALING PENTING!)\n\n### Cara 1: Menggunakan Script (RECOMMENDED)\n\n```bash\n./scripts/start-stack.sh\n```\n\nOutput harusnya:\n```\n========================================\nStarting Docker Monitoring Stack\n========================================\n\n[1/3] Checking Docker daemon...\n[2/3] Creating configuration directories...\n[3/3] Starting containers...\n\n========================================\nStack started successfully!\n========================================\n\nAccess the services at:\n  • Portainer:   http://localhost:9000\n  • Grafana:     http://localhost:3000 (admin / admin123)\n  • Prometheus:  http://localhost:9090\n  • Loki:        http://localhost:3100\n\nView logs with:\n  docker compose logs -f\n```\n\n### Cara 2: Manual dengan Docker Compose\n\n```bash\n# Start dalam background\ndocker compose up -d\n\n# Lihat logs\ndocker compose logs -f\n\n# Lihat status containers\ndocker compose ps\n```\n\n---\n\n## ✅ STEP 6: Verifikasi Containers Running\n\n```bash\ndocker compose ps\n```\n\nHarusnya output seperti ini:\n```\nCONTAINER ID   IMAGE                              STATUS\n...\nportainer      portainer/portainer-ce:latest      Up 2 minutes\nprometheus     prom/prometheus:latest             Up 2 minutes\nloki           grafana/loki:latest                Up 2 minutes\npromtail       grafana/promtail:latest            Up 2 minutes\ngrafana        grafana/grafana:latest             Up 2 minutes\nnode-exporter  prom/node-exporter:latest          Up 2 minutes\ncadvisor       gcr.io/cadvisor/cadvisor:latest    Up 2 minutes\n```\n\n**Jika ada yang `Exited`, check logs:**\n```bash\ndocker compose logs nama_container\n# Contoh:\ndocker compose logs grafana\ndocker compose logs prometheus\n```\n\n---\n\n## 🌐 STEP 7: Akses Dashboard\n\n### Dapatkan IP Ubuntu Server\n\n```bash\nip addr show\n# atau\nhostname -I\n```\n\nCari IP yang format `192.168.x.x` atau `10.x.x.x`\n\n### Buka di Browser (dari Laptop)\n\n| Service | URL | Username | Password |\n|---------|-----|----------|----------|\n| **Portainer** | `http://192.168.x.x:9000` | Setup Awal | - |\n| **Grafana** | `http://192.168.x.x:3000` | admin | admin123 |\n| **Prometheus** | `http://192.168.x.x:9090` | - | - |\n| **Loki** | `http://192.168.x.x:3100` | - | - |\n\n**Contoh:**\n```\nhttp://192.168.1.100:9000\nhttp://192.168.1.100:3000\n```\n\n---\n\n## 🔐 STEP 8: Setup Portainer (First Time)\n\n### 8.1 Buka Portainer\nGo to: `http://192.168.x.x:9000`\n\n### 8.2 Isi Form Setup\n\n1. **Username**: `admin` (atau yang Anda inginkan)\n2. **Password**: Masukkan password yang kuat\n3. **Confirm Password**: Ulangi password\n4. Click **Create user**\n\n### 8.3 Connect ke Local Docker\n\n1. Select **Docker**\n2. Click **Connect**\n3. Dashboard akan menampilkan containers yang running\n\n---\n\n## 📊 STEP 9: Setup Grafana\n\n### 9.1 Login Pertama\n\nGo to: `http://192.168.x.x:3000`\n\n- **Username**: `admin`\n- **Password**: `admin123` (atau yang Anda ubah di `.env`)\n\n### 9.2 Data Sources Sudah Ter-setup\n\nGo to **Configuration** → **Data Sources**\n\nHarusnya sudah ada:\n- ✅ **Prometheus** (http://prometheus:9090)\n- ✅ **Loki** (http://loki:3100)\n\n### 9.3 Buat Dashboard Pertama\n\n1. Go to **Dashboards** → **New Dashboard**\n2. Click **Add visualization**\n3. Select **Prometheus** data source\n4. Query contoh:\n   ```promql\n   up\n   ```\n   (Lihat semua services yang up/down)\n\n---\n\n## 📈 STEP 10: Query Metrics di Prometheus\n\nGo to: `http://192.168.x.x:9090`\n\n### Examples queries:\n\n**1. CPU Usage:**\n```promql\n100 - (avg by (instance) (rate(node_cpu_seconds_total{mode=\"idle\"}[5m])) * 100)\n```\n\n**2. Memory Usage:**\n```promql\n(1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100\n```\n\n**3. Disk Usage:**\n```promql\n(1 - (node_filesystem_avail_bytes / node_filesystem_size_bytes)) * 100\n```\n\n**4. Service Status (UP/DOWN):**\n```promql\nup\n```\n\n---\n\n## 📝 STEP 11: View Logs di Loki (Grafana)\n\n### 11.1 Buka Grafana\n`http://192.168.x.x:3000`\n\n### 11.2 Go to Explore\n\n1. Click **Explore** (icon kompas)\n2. Select **Loki** di dropdown data source\n3. Pilih Label:\n   - `job` → pilih job (syslog, auth, docker, dll)\n4. Click **Run Query**\n\n### 11.3 Example Queries:\n\n**Cari SSH failed login:**\n```logql\n{job=\"auth\"} |= \"Failed password\"\n```\n\n**Cari Docker errors:**\n```logql\n{job=\"docker\"} |= \"error\"\n```\n\n**Cari semua logs auth:**\n```logql\n{job=\"auth\"}\n```\n\n**Cari kernel warnings:**\n```logql\n{job=\"kernel\"} |= \"warning\"\n```\n\n---\n\n## 🛑 STEP 12: Stop/Restart Stack\n\n### Stop Stack\n\n```bash\ndocker compose down\n```\n\nAtau gunakan script:\n```bash\n./scripts/stop-stack.sh\n```\n\n### Start Kembali\n\n```bash\ndocker compose up -d\n```\n\nAtau:\n```bash\n./scripts/start-stack.sh\n```\n\n### Lihat Logs\n\n```bash\n# Semua services\ndocker compose logs -f\n\n# Service spesifik\ndocker compose logs -f grafana\ndocker compose logs -f prometheus\ndocker compose logs -f loki\n\n# 50 baris terakhir\ndocker compose logs --tail 50 -f\n```\n\n---\n\n## 🔧 Troubleshooting\n\n### Problem 1: Permission Denied saat jalankan docker\n\n**Solution:**\n```bash\nsudo usermod -aG docker $USER\nnewgrp docker\n# atau logout dan login ulang\n```\n\n### Problem 2: Port sudah digunakan\n\n**Cek port yang digunakan:**\n```bash\nsudo netstat -tulpn | grep LISTEN\n```\n\n**Ubah port di docker-compose.yml:**\n```yaml\nports:\n  - \"8080:9000\"  # ubah 8080 ke port yang kosong\n```\n\nKemudian:\n```bash\ndocker compose down\ndocker compose up -d\n```\n\n### Problem 3: Containers tidak start\n\n**Check logs:**\n```bash\ndocker compose logs\n```\n\n**Restart containers:**\n```bash\ndocker compose restart\n```\n\n**Rebuild dari awal:**\n```bash\ndocker compose down -v\ndocker compose pull\ndocker compose up -d\n```\n\n### Problem 4: Tidak bisa akses dari browser\n\n**Cek IP Ubuntu Server:**\n```bash\nip addr show\n```\n\n**Cek firewall:**\n```bash\nsudo ufw status\n# Jika aktif:\nsudo ufw allow 9000\nsudo ufw allow 3000\nsudo ufw allow 9090\nsudo ufw allow 3100\n```\n\n**Cek containers running:**\n```bash\ndocker compose ps\n```\n\n---\n\n## 📚 Useful Commands\n\n```bash\n# Check docker compose version\ndocker compose version\n\n# Validate config\ndocker compose config\n\n# Scale services\ndocker compose up -d --scale prometheus=2\n\n# Remove containers but keep volumes\ndocker compose down\n\n# Remove containers AND volumes\ndocker compose down -v\n\n# Prune unused containers/images\ndocker system prune -a\n\n# Check Docker disk usage\ndocker system df\n\n# View specific container logs\ndocker logs container_name\n\n# Enter container shell\ndocker exec -it grafana /bin/bash\n\n# Restart specific service\ndocker compose restart prometheus\n```\n\n---\n\n## 🎉 Selesai!\n\nSekarang Anda punya monitoring stack yang lengkap untuk:\n- ✅ Monitor logs server\n- ✅ Monitor jaringan\n- ✅ Monitor containers\n- ✅ Dashboard visual dengan Grafana\n- ✅ Alert management dengan Prometheus\n- ✅ Management Docker dengan Portainer\n\n---\n\n## 📞 Support\n\nJika ada masalah, cek:\n1. Docker sudah terinstall: `docker --version`\n2. Docker compose sudah bisa dijalankan: `docker compose version`\n3. Config file valid: `docker compose config`\n4. Containers running: `docker compose ps`\n5. Check logs: `docker compose logs`\n\n**Happy Monitoring! 🚀**\n
